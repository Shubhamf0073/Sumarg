# 04 — Training, parent invites, go-live and hypercare

## Crew training (45 minutes per batch, in Gujarati/Hindi, at the depot)
1. Install the app, sign in with school code + mobile + PIN (set on first login).
2. Before the trip: inspection checklist; Start trip.
3. During the trip: children tap the card at the door — green light + name = OK, red = tell the attendant;
   manual mark when a card is forgotten; never mark a child who is not on the bus.
4. SOS: press and hold the red button (or the app's SOS) — the school is alerted with location; the key clears it.
5. End trip: the app warns if a child has not got off — **check every seat** before ending.
6. Hand out the quick card (`quick-cards/driver-attendant.md`).

## Transport desk training (60 minutes)
Live board, alerts inbox (acknowledge/resolve), SOS handling procedure (who calls whom), absences and requests,
crew and vehicle documents expiry, reports, adding/moving a student, issuing a replacement card.

## Parent invites
- The school sends the invite SMS (DLT template "Invite", docs/15 §5) from the portal; also a WhatsApp message in
  class groups with the same link, and an A4 **QR poster** at the gate and in the bus.
- Parents install, enter school code + mobile → OTP → see their children. Unknown mobiles get the same neutral
  response (docs/05) — the school adds them if needed.
- Target: **≥ 70 % of transport students with at least one active guardian by day 10.**

## Go-live day
- Previa support watches both runs on the live board; one person on call for the transport desk.
- Check per bus: trip started, taps arriving with photos, ETA pushes going out, trip ended with everyone dropped.

## Hypercare (days 1–10): daily one-page report to the school
| Metric | Target |
|---|---|
| Buses reporting during runs | 100 % |
| Tap coverage (taps ÷ students expected on board) | ≥ 95 % by day 5 |
| Manual marks | < 5 % by day 5 (higher = card or reader issue) |
| Parent activation | ≥ 70 % by day 10 |
| SOS false alarms | 0 after day 3 (else re-site the button) |
| Units offline > 30 min during a run | 0 |

Close hypercare when the targets hold for three days; set `onboarding_stage = live`.
